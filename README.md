# 大肥鱼 AI 聊天助手

当前版本：**1.18.19**。包含游戏插件、Windows x64 桌面助手源码、安装脚本和 API 接入说明。

## 直接使用

到 [Releases](https://github.com/Shiki233580/wow-ai-chat/releases/tag/v1.18.19) 下载 `wow-ai-chat-1.18.19-share.zip`，完整解压。

1. 运行 `setup.bat`，填写自己的游戏路径、完整角色名和 DeepSeek API Key。
2. 运行 `install-addon.bat`，再运行 `run.bat`。
3. 游戏中启用插件并 `/reload`；`/dfy` 显示工具栏。
4. 先选频道并手动生成验收，再按需要开启总控和自动回复分项。

私有仓库及其安装包仅对有仓库访问权限的人可见。分享给其他人，需要先授予仓库访问权限，或者直接发送 ZIP。

## 从源码构建

需要 Windows 和 .NET 8 SDK。克隆后运行 `build.bat`，生成自包含的 `WhaleChat.exe`；再运行 `setup.bat`。
源码仓库不包含大型 EXE；可运行版本在 Releases。`setup.bat` 会从 `config.example.json` 创建被 Git 忽略的个人配置。

## 功能

- 聊天上下文、手动生成与润色、预览发送和丢弃。
- 角色/战网私聊、密集私聊处理、锁定频道的公开自动回复。
- 自己的信号、任务与奖励、可信来源的稀有装备发言。
- 任务合并、制作隔离、讨水与收水感谢、统一自动总控。
- 大肥鱼人设及回复前缀；确认发送后清空预览。

## 本版修复与限制

修复 F1～F12 全被已有技能/背包绑定占用时无法连接的问题。只选择确认未绑定的其他普通键，禁止注入 Ctrl/Shift/Alt，不覆盖现有绑定。
**无需用户操作全局快捷键，但后台仍使用普通按键通信，不是零模拟输入方案。**游戏前台、聊天输入焦点、通信区遮挡和客户端保护状态会影响通信。

作者环境已观察到真实握手和一条战网私聊发送确认、预览清空；其余功能经过离线回归。不同客户端版本、键盘布局和插件组合需重新验收，不保证通用兼容。

## 接入与隐私

完整用法见 [README.txt](README.txt)，API 配置见 [API接入说明](API接入说明.md)。完整功能需要使用者自己的 DeepSeek API Key。

不要提交 `config.json`、`credentials.yaml`、日志、聊天记忆、WTF 或任何个人令牌。提供的人设已移除作者的固定角色绑定。
聊天上下文会发送到 AI 服务；自动化可能违反游戏服务条款并带来账号处罚风险，请先确认自己接受。

本仓库目前未声明开源许可证；私有可见性不等于向所有人授予再分发许可。
