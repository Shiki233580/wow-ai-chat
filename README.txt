大肥鱼 AI 聊天助手 1.18.19（Windows x64）

一、先配置，再启动
1. 把整个压缩包解压到可写目录，不要直接在 ZIP 内运行。
2. 双击 setup.bat，填写本机 Wow.exe 的完整路径、角色名-服务器，以及你自己的 DeepSeek API Key。
   角色必须与游戏返回的完整名字一致。原作者的角色绑定和密钥没有打包。
3. 双击 install-addon.bat，把插件安装到该客户端的 Interface\AddOns\DaFeiYu。
   已有插件会先备份到本包 backups 目录；若 Program Files 权限不足，以管理员身份运行该安装脚本。
4. 双击 run.bat。助手在托盘运行，不需要安装 .NET，也不需要操作任何组合快捷键。
5. 游戏中启用“大肥鱼”，输入 /reload。/dfy 打开聊天工具栏，/dfy settings 打开设置。
6. 等到 IDLE，选择回复频道。先点“生成”检查预览，再点“发送”。确认无误后按需要打开“总控”和各分项。

二、功能与开关
- 手动生成、场景提示润色、待发预览编辑、发送、丢弃。
- 角色私聊/战网私聊：上下文独立；同人密集消息合并，多人消息分开处理。
- 小队等公开回复：受工具栏当前锁定频道限制；其他勾选频道不应串台回复。
- 自己的标记、任务/领奖、稀有装备事件发言。装备仅识别赢得分配或任务奖励等可信来源，不因穿脱装备触发。
- 交接任务合并、制作窗口隔离，避免铜锭等材料连续入包引发大量发言。
- 选中友方法师点“讨水”；开启总控及感谢分项后，交易确认收到水自动感谢。
- 总控关闭会停止自动处理，不能靠分项开关偷偷恢复；手动操作仍可用。
- 回复带【大肥鱼】前缀，发送确认后清空预览。结果未确认时不盲目重复发送。

三、API、人设和隐私
完整功能需要你自己的 DeepSeek Key，按使用量计费。详见 API接入说明.md。
默认人设文件为 persona-大肥鱼.txt，已移除原作者的固定角色身份，可自行编辑；修改后重启助手。
当前版本配置人设时，以及私聊/公开自动回复/信号/场景/事件模式，直接调用 DeepSeek 官方 HTTPS 接口。
apiUrl 的本地接口兼容模式仍保留，但只改本地 URL 不等于已接通所有功能。
选中频道/私聊的上下文、部分角色场景信息和最近自身回复会发给所选 AI 服务。
运行后 logs、reply-memory.json、seen-requests.json 等可能包含聊天内容，不要未经清理再次分享运行目录。
credentials.yaml 是本机明文密钥文件；不要公开、上传或发给别人。包内只有空白示例，没有原作者密钥。

四、重要限制和风险
- 取消的是全局/手动快捷键，不是完全取消后台键盘输入。普通插件无法直接请求 HTTP，因此桌面助手读取游戏通信区，并用确认未绑定的普通按键回传。
- 不注入 Ctrl/Shift/Alt，不覆盖已有技能/背包绑定，不用聊天框粘贴或自动按 Enter。
- F1～F12 全被占用时，会寻找未绑定的导航键、小键盘运算符或标点键；仍无可用键则拒绝连接，而不是占用用户动作。
- 游戏必须在前台、通信区域没有被遮挡；打字、用户按住通信冲突键或窗口切换会中断/等待。切回后自动恢复，不需要反复点重连。
- 客户端战斗保护可能阻止首次设置绑定，解除保护后再初始化；制作窗口有独立隔离，不要通过关闭保护强制发言。
- 当前 TOC Interface=16001，已在作者的对应客户端验收；其他版本、键盘布局、插件组合未逐一实测，不保证跨客户端直接兼容。
- 自动化可能违反游戏服务条款，存在账号处罚风险。分享前应向使用者说明，不保证零风险。

五、常见问题
一直 OFFLINE：检查助手是否运行、路径/角色是否正确、游戏是否前台、通信区是否被遮挡；再看 logs 当日日志。
界面没有更新：确认不是 AddOns\DaFeiYu\DaFeiYu 嵌套，检查游戏启用插件并 /reload。
生成不发送：手动生成只提供预览；自动模式需要总控及对应分项开启，回复目标可用。
私聊不回复：检查总控、私聊分项；不要仅打开公开频道自动。
API 401/余额不足：更换自己的 Key 或给 API 账户充值；ChatGPT 网页订阅不提供此接口额度。
不要为了连接清空自己的 F 键或开启复杂组合键。

六、升级、源码和验证
升级前退出旧托盘助手并备份旧目录。解压新包，保留/迁移自己的 config.json、credentials.yaml 和自定义人设，再运行安装脚本和 /reload。
build.bat：需 .NET 8 SDK，构建 win-x64 自包含单文件 EXE；首次构建可能需要网络恢复依赖。
sha256-manifest.json：包内逐文件校验值。压缩包旁的 .sha256 用于校验 ZIP。
本版实际观察到 IDLE 握手；一条正常战网私聊完成 AI生成→回传→发送→游戏确认，预览清空。
其他功能经过离线事件/API模拟回归；不把离线通过冒充所有场景的实际游戏验收。
